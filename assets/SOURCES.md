# Visual sources

- Application screenshots (`images/app/screen-*.webp`): the public PetNudge App Store listing, app ID 6756539814. Downloaded from Apple's iTunes lookup API for France on 2026-10-09. These are actual app screens, not recreated interfaces. Order: welcome, AI, tracking, reminders, security, home, health, medal.
- Golden retriever photograph (`images/companion-dog.jpg`): Unsplash, photo ID `photo-1552053831-71594a27632d`, https://images.unsplash.com/photo-1552053831-71594a27632d. Used as an illustrative companion photograph, not as a testimonial or an identified app user's pet.
- DM Sans and Instrument Serif: Google Fonts, self-hosted under `assets/fonts/`; SIL Open Font License. License texts are included with the fonts. WOFF2 files were losslessly compressed from the original font files for faster loading.
- Existing medal photographs: original project assets, retained in the shop and medal sections.

The journal uses an intentional text-led editorial layout. A complete visual review of 228 unique upstream images found many unrelated scenes and synthetic artifacts; several generic photographs remain usable, but none is required to understand the articles. Initial automated requests returned HTTP 403; browser-user-agent requests returned HTTP 200, so those images are not described as broken. See `docs/blog-seo-audit.md` for the visual assessment.

- Social preview (`images/social-preview.jpg`, 1200×630): screenshot of the actual redesigned homepage, rendered with the local typefaces and real app imagery on 2026-10-09.
